# The Weeknd Tracklist Challenge

inspirado no jogo "Países do Mundo" do site JetPunk, crie um quiz em que o player deve escrever o nome de todas as músicas do the weekend com um timer. as músicas são sepradas por album e conforme o player escreve o nome da música, a tracklist de cada album é preenchida
